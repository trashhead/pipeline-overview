# CI/CD Overview

One page that shows what is running and what is deployed, across all pipelines in a project.

## What you get

- **Latest deployment per stage** - for example which version is currently in Test and Prod.
- **Recent runs per pipeline** with a pill per stage (Build, Test, Prod ...), newest first.
- **Live status** - running stages show a spinner, and the page refreshes automatically.
- **Waiting for approval** - a stage that waits for approval is highlighted and links to the run, where you approve as usual.
- Filter by keyword and put failed, partial or cancelled pipelines on top.

## Permissions

Read-only. The extension only asks for permission to read builds and project information. It cannot start, change or approve anything.

## Where to find it

Pipelines > CI/CD Overview.
